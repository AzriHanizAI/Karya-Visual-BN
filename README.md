# Karya Visual BN — Interactive Client Intake, Cost Estimator & Booking Portal

**Live Demo:** https://karya-visual-bn.lovable.app/

## The Business Problem
Service-based businesses in Brunei—such as film production houses, photography studios, car detailing centers, and interior designers—lose high-intent leads after office hours. Staff spend hours manually replying to repetitive WhatsApp/Instagram DMs asking for package prices, project specs, and calendar availability.

## The Solution
A full-stack, mobile-first client intake and booking web application built specifically for Bruneian service workflows:
* **Interactive Scope & Cost Estimator (BND):** Clients select project requirements (shoot duration, district travel surcharges, add-ons) and get an instant, transparent price range.
* **Real-Time Consultation Booking:** Integrated calendar allowing prospective clients to lock in available consultation slots without back-and-forth messaging.
* **Admin Booking Desk:** A private dashboard for business owners to review incoming project briefs, approve bookings, and manage lead statuses.

## Tech Stack & Architecture
* **Frontend:** React, TypeScript, Tailwind CSS (Responsive Mobile & Desktop)
* **Backend & Database:** Supabase (PostgreSQL, Authentication, Row-Level Security)
